# ShoppingApp-Basic-

A simple Shopping List Android application built using **Jetpack Compose**. This app allows users to add items to a shopping list dynamically.

## 📱 Features

- Add items to a shopping list
- Built entirely with **Jetpack Compose**
- Clean and minimal UI using **Material3**
- Basic state handling for UI updates

---

## 🚀 How to Set Up and Run the Project

1. **Clone the repository**


git clone https://github.com/aayush0401/ShoppingApp-Basic-.git

 Dependencies & Configuration
Make sure your setup meets the following requirements:

Android Studio Giraffe or higher

Gradle Plugin Version: 8.3.2

Kotlin Version: 1.9.22

Jetpack Compose Compiler: 1.5.10

Libraries Used:

androidx.activity:activity-compose

androidx.compose.material3:material3

androidx.compose.ui:ui

androidx.lifecycle:lifecycle-runtime-ktx

All dependencies are managed via Version Catalog (libs.versions.toml).
